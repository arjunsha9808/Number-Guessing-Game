# Number Guessing Game

A simple *Number Guessing Game developed using Java*. In this console-based game, the computer generates a random number, and the player tries to guess it. The program provides hints after each attempt to help the player find the correct number.

## 👨‍💻 Author

*Arjun Sharma*

Java Backend Developer | Java | Spring Boot | MySQL

## 🚀 Features

- Generates a random number
- Accepts user guesses
- Provides hints:
  - Guess is too high
  - Guess is too low
  - Correct guess
- Counts the number of attempts
- Console-based user interaction
- Simple and beginner-friendly implementation

## 🛠️ Technologies Used

- Java
- Core Java
- Scanner
- Random
- Loops
- If-Else Statements
- Variables and Data Types
- Basic Problem-Solving
